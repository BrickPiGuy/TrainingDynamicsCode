# Kanban Calendar Board

A lightweight web application with:

- a three-column Kanban board (`To Do`, `Doing`, `Done`)
- drag-and-drop task movement
- due dates for tasks
- a monthly calendar that displays tasks on their scheduled date
- local storage persistence

## Run it

Because the app is fully static, you can either:

1. Open `index.html` directly in a browser, or
2. Serve the folder locally with a simple static server

Example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
